Guides explain one Sapporta subsystem or operating activity independently. Each page names the system boundary, applies it to the task app, defines verification, and links exact lookup material to Reference.

## Guide groups

- **Model data.** Define tables, relationships, migrations, search, indexes, and display metadata. [Open the first guide](/docs/guides/model-data/tables-columns-and-schema-metadata/).
- **Generated application surfaces.** Use record screens, table APIs, shared queries, and table-aware grids. [Open the first guide](/docs/guides/generated-surfaces/record-screens-and-forms/).
- **Security.** Apply authentication, abilities, row visibility, safe custom data access, and scoped tokens. [Open the first guide](/docs/guides/security/authentication-and-abilities/).
- **App-owned features.** Build contracts, endpoints, workflows, typed clients, and protected screens. [Open the first guide](/docs/guides/app-owned-features/custom-api-endpoints/).
- **Reports.** Build route-based datasets, formatting, links, and scoped aggregates. [Open the first guide](/docs/guides/reports/route-based-reports/).
- **Discovery and operations.** Discover interfaces, use the CLI and agents, configure, deploy, migrate, and troubleshoot. [Open the first guide](/docs/guides/discovery/openapi-and-endpoint-discovery/).
