So, in this walkthrough, we will build an entire invoicing application using Sapporta. It will have the following concepts. It will have the concept of an invoice, a client, and each client will have multiple contact points. And we will also receive payments for each invoices. That should be it. So when we begin, we always begin by modeling what the data that we're going to collect is. So that is going to be the table modeling. And for this, we'll use Drizzle as well as the Sapporta metadata. So that's what we're going to do first. So the first setup is modeling the data, modeling the domain using DRESL and Sapota table metadata. That's number one. Then, number two will be we will take a look at how that is going to render into the system and it will have screenshots of how that is going to be displayed and we will then for each of these schema specifications we will add the children so we'll go step by step we'll add the first basic master table which is going to be clients and then clients will have only the basic information then we will add a related concept called a contact that belongs to a client and for each of these we'll show how it is going to be rendered in the screen and then we will have this contacts this contacts becoming children of the client so that we can see in the grid how that relationship is added and maintained then we'll see the forms where we can add new clients and where we can add new contacts for each client then we will work on building a small custom React screen where we can add a contact we can see all the clients and their contacts and we can add a contact for a client without having to select the client in the form
