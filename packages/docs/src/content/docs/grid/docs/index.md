Sapporta Grid is the standalone React grid package used by Sapporta's generated
table screens. You can use it in any React app.

Start with [Getting Started](/grid/docs/getting-started/) if you want a small
editable grid on the page first. Move to [Core Model](/grid/docs/core-model/)
when you need to understand levels, row paths, columns, and data sources.

Use full Sapporta only when you want the backend pieces around the grid:
schema-as-code tables, generated APIs, row security, OpenAPI, reports, and the
app shell.
