## Identity

`@sapporta/grid` 0.2.7 supports the root export, `./grid`, `./advanced`,
`./column-preset`, `./lookup`, `./lookup/react`, and `./index.css`.

## Reference groups

- [GridCore](/grid/reference/grid-core/) — schema and identity, grid and level
  runtimes, React APIs, row operations, drafts, and advanced composition.
- [ColumnPreset](/grid/reference/column-preset/) — typed column constructors, editors, formatting, copy, and sizing.
- [Data sources](/grid/reference/data-sources/) — custom contracts, runtime
  access, writes, reconciliation, and built-in adapters.
- [Interactions](/grid/reference/interactions/) — configuration, active rows,
  activation, and row selection.
- [Grid DOM state contract](/grid/reference/dom-and-styling-contract/).

Behavioral guides own the complete
[copying](/grid/guides/copying-grid-data/) and
[styling](/grid/guides/styling/) workflows. The
[Clipboard API](/grid/reference/clipboard/) and
[REST data-source helpers](/grid/reference/rest-helpers/) pages preserve the
older reference URLs and route to those canonical pages.

`TGrid`, `TableRoute`, and `SchemaTableGridView` are `@sapporta/frontend` contracts documented in the main [TGrid Reference](/docs/reference/frontend/tgrid/).
