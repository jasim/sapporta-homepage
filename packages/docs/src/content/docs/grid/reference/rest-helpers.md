## Identity

REST data-source helpers are exported from `@sapporta/grid/grid`.

The canonical reference is
[In-memory and REST data sources](/grid/reference/data-sources/in-memory-and-rest-sources/).
It covers `restLevelSource()`, `restGridDataSource()`, request construction,
source-owned query state, and host-backed query state.

Use [Data-source writes and reconciliation](/grid/reference/data-sources/writes-and-reconciliation/)
for remote persistence and authoritative results.
