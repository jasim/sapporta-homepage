## Agentic use out of the box

Applications built with Sapporta offer full agentic access without insecure
exposure. `/api/openapi.json` exposes every registered endpoint and table
operation, giving agents complete access to all APIs and tables. Row-level
security and CASL authorization enforce scope on every call.

**Freeform data entry using agents:** If you build a calorie tracking system
with Sapporta, you can scribble your meal details in shorthand freeform however
you want in your coding agent. Like "about 2 hours ago, brekkie - toast butter
with 2 banans". You could use dictation for all it mattered. The coding agent
will then talk to your Sapporta app to map the individual food items into the
ones already in your database, and convert it into valid structured form and
enter it. And in case the food item doesn't exist, it'll automatically create
it, find its standard calorie and nutrition information, and then link them up.
All this without any extra work - the table APIs generated by Sapporta, along
with the Skill file, lets the agent to complex multi-step workflows without any
additional code.

**Complex multi-step queries:** In the personal book-keeping system I've built
using Sapporta, I can point an agent at it and ask it to figure out why my
computed bank balance doesn't match, and it will do the kind of analysis it
would have taken me sometimes hours of drudgery, and figure out the exact
transactions that might be duplicated, or missing from the system, or other
errors.
