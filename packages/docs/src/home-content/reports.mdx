## Reports with expandable detail

Sapporta reports display read-only results in a data grid. A report can contain a single list of rows or multiple nested
levels—for example, accounts with their journal entries underneath.

Users can sort the returned rows, resize columns, expand nested rows, and copy values. Reports can include rollup,
opening, closing, subtotal, and footer rows. Columns support text, numbers, booleans, dates, timestamps, currency,
percentages, multiline text, and Markdown.

Individual cells can link to another report, a record page, an application route, or an external URL. Hidden columns can
carry the IDs needed for those links without displaying them. With the keyboard, Space expands a nested row and Enter
follows the configured link for the active cell.

Each report defines its own inputs and surrounding screen. Sapporta provides reusable components for the page frame,
parameter toolbar, date ranges, run button, errors, summary statistics, and result grid.
