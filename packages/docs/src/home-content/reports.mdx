## Reports with drill-down

A report is one API endpoint returning a common wire format — sorting,
exporting, nesting, and deep links all come from the framework.

**One wire format instead of ad-hoc HTML.** When an LLM writes reporting code
from scratch, exporting, sorting, and filtering get tangled into each
report's rendering logic, ad hoc, every time. In Sapporta the endpoint
returns a `GridDataset` and the ReportGrid component renders it with the
Sapporta Grid, so those concerns stay cleanly separated.

**Nested levels.** Reports can render multiple levels: rows in an Account
Ledger expand to show their journal entry, giving full context for each
transaction without leaving the report.

**URL deep-linking.** A report's parameters and drill-downs are captured in
the URL, so any report configuration can be shared as a link.

**Built-in primitives.** Rollups, subtotals, opening rows, and closing rows
are first-class.

**Full keyboard.** Space expands nested rows; Enter follows the active
cell's link.

**Composable.** Argument inputs, error display, and summary stats are React
components your code can compose, extend, or replace wholesale for fully
custom experiences.
