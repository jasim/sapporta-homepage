## Reports with drill-down

A report is one API endpoint returning a common wire format. Sorting,
exporting, nesting, and deep links all come from the framework.

**One wire format instead of ad-hoc HTML.** Written from scratch, exporting,
sorting, and filtering end up mixed into each report's rendering code,
differently every time. In Sapporta the endpoint
returns a `GridDataset` and the ReportGrid component renders it with the
Sapporta Grid, so rendering stays separate from those concerns.

**Nested levels.** Reports can render multiple levels: rows in an Account
Ledger expand to show their journal entry, so you get the full context of a
transaction without leaving the report.

**URL deep-linking.** A report's parameters and drill-downs are kept in the
URL, so you can share any report configuration as a link.

**Built-in primitives.** Rollups, subtotals, opening rows, and closing rows
are supported directly.

**Full keyboard.** Space expands nested rows; Enter follows the active
cell's link.

**Composable.** Argument inputs, error display, and summary stats are React
components your code can reuse, extend, or replace entirely.
